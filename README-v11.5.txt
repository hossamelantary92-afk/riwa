Riwa v11.5 — Compact Book Picker

What changed:
- Smaller «اختارلي كتاب» dialog and its cover animation.
- Compact selection, search, book chips and responsive mobile layout.
- Search results list can scroll internally when there are many results.

Install:
1. Back up existing site.
2. Replace index.html in GitHub/Vercel with this version.
3. Leave logo.svg and reading-corner.svg next to index.html.
4. Hard refresh after deploy.

No SQL needed.
